# Produktvideo – manus (ca 55 s)

Filen `produktvideo.mp4` är inspelad direkt från prototypen och har svenska textremsor. Det
här manuset kan läsas in som berättarröst ovanpå videon (tiderna är ungefärliga).

| Tid | Bild | Berättarröst |
|---|---|---|
| 0–5 | Titelkort: *Måltider – Ingrid, 78, väljer sin mat själv* | Det här är Ingrid. Hon är 78 och återhämtar sig efter en operation. Maten är det hon ser fram emot. |
| 5–11 | Armbandet mot plattan | Hon loggar in med sitt sjukhusarmband – inget att skriva, ingen telefon, inget BankID. |
| 11–19 | Hennes beställningar, med måltidsraden och kosten överst | Direkt ser hon vad hon har beställt – nästa måltid överst, det som har passerat i grått. Kosten står alltid överst, och bara personalen kan ändra den. |
| 19–25 | Tummen upp på gårdagens middag | Hur smakade gårdagens middag? Ett tryck, och köket vet. |
| 25–31 | Måltidsraden med nedräkning | Frukost, lunch, fika, middag – eller något litet när hon vill. Nedräkningen visar hur länge hon kan beställa. |
| 31–39 | Menyn med bilder och förslaget | Hon bläddrar bland bilder i lugn och ro. Hon ser bara mat som passar henne, och ett förslag med skälet. |
| 39–45 | Liten portion, skuren i bitar | Lite aptit idag? Liten portion, skuren i bitar. |
| 45–50 | Dryck och "Stämmer det här?" | Hon ser allt innan hon beställer. |
| 50–53 | "Tack Ingrid! kl 12:00" | Klart. Maten kommer till rummet klockan tolv. |
| 53–55 | Språkbyte till arabiska | På svenska, engelska eller arabiska – med uppläsning och större text. |
| 55–57 | Slutkort | Måltider. Mat hon vill äta – vald av henne själv. |

**Spela in videon igen** efter ändringar: starta appen (`npm run build && npx next start -p 3129`)
och kör inspelningsskriptet som beskrivs i README.
