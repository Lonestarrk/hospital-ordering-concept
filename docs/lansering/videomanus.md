# Produktvideo – manus (58 s)

Filen `produktvideo.mp4` är inspelad direkt från prototypen och har svenska textremsor. Det
här manuset kan läsas in som berättarröst ovanpå videon (tiderna stämmer med bilden).

| Tid | Bild | Berättarröst |
|---|---|---|
| 0–5 | Titelkort: *Måltider – Ingrid, 78, väljer sin mat själv* | Det här är Ingrid. Hon är 78 och återhämtar sig efter en operation. Maten är det hon ser fram emot. |
| 5–12 | Inloggning med stort sifferblock | Hon loggar in med sitt personnummer – stora siffror, ingen telefon, inget BankID. |
| 12–17 | "Hej Ingrid! Stämmer det här?" med kost och allergier | Appen vet redan vad hon får äta. Bara personalen kan ändra det. |
| 17–25 | Introduktion i tre steg | Första gången får hon en kort introduktion – och hjälp finns alltid i hörnet. |
| 25–31 | Tummen upp på gårdagens middag | Hur smakade gårdagens middag? Ett tryck, och köket vet. |
| 31–38 | Menyn med bilder och förslaget | Hon bläddrar bland bilder i lugn och ro. Hon ser bara mat som passar henne, och ett förslag med skälet. |
| 38–45 | Liten portion, skuren i bitar | Lite aptit idag? Liten portion, skuren i bitar. |
| 45–51 | Dryck och "Stämmer det här?" | Hon ser allt innan hon beställer. |
| 51–54 | "Tack Ingrid! kl 12:00" | Klart. Maten kommer till rummet klockan tolv. |
| 54–56 | Språkbyte till arabiska | På svenska, engelska eller arabiska – med uppläsning och större text. |
| 56–58 | Slutkort | Måltider. Mat hon vill äta – vald av henne själv. |

**Spela in videon igen** efter ändringar: starta appen (`npm run build && npx next start -p 3129`)
och kör inspelningsskriptet som beskrivs i README.
